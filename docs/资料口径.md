# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

pack_id是物理容器，material_id是物质。开封后容器计数仍为1直到明确销毁；分装新管增加空包装数而非新入区材料。密度只在物质、时间和temperature_c均适用时换算ml到g，无插值授权。规格按packaged_at适用，净重不含容器。称量容差0.2g，超差待核，不自动生成损耗。issue/return/transfer只变保管方，use才是实际实验消耗；evaporate和destroy单列。成本按原包装取得价每克归属；未知质量不能伪造成本。实际消耗时点决定项目成本期，handover_period为提出的核销期，只有confirmed use、documented evaporate、witnessed destroy具确认资格，pending不可自动核销。density_corrections是后续单独接收的整行数值补正。

## materials
物质及成本。

记录键：['material_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| material_id | string | 物质 |
| yuan_per_g | number | 元每克 |

## density_corrections
后续密度补正。

记录键：['correction_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| correction_id | string | 补正 |
| density_id | string | 目标 |
| g_per_ml | number | 新密度 |
| received_at | datetime | 收到 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

子管产生时继承父管保管方及单位成本，未知质量保留待核。pending处置有申报但未足证，不同时按确认损失和可用余量计两次。空包装计数与原始进口包装数分开，分装不增加进口数量。
